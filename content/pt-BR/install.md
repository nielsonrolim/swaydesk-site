Os pacotes para o Debian 13, o Ubuntu 26.04 e o Arch Linux vão sair por um repositório no [Open Build Service](https://build.opensuse.org/). Assim que ele passar nos testes, as instruções completas aparecem aqui.

## O que você vai precisar

- Debian 13, Ubuntu 26.04 ou Arch Linux, com ou sem outro desktop instalado. O desktop que você já tem continua na tela de login.
- Uma placa de vídeo Intel, AMD ou NVIDIA com driver para Wayland.
